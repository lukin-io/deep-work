# Deep Work 0.1.0 — preview 2

This Apple Silicon preview includes the implemented work from Stages 1–6: the focus timer and durable history, Journal reports and work schedules, CSV export, local feedback, native services, and keyboard/layout/lifecycle fixes. **127 of 137 product items are accepted**; the remaining manual and external checks are listed below. This is an ad hoc signed, unnotarized preview, not a stable release.

## Download and install

Download **Deep-Work-v0.1.0-preview.2-macOS-arm64.zip** from Assets, extract it, and move **Deep Work.app** to Applications. GitHub's automatic Source code archives do not contain the installed app. Requires **Apple Silicon (M1 or later) and macOS 15+**; Intel Macs and older macOS are unsupported.

Before replacing an earlier copy, **quit it successfully**. For an upgrade from preview 1, back up the entire `~/Library/Application Support/app.deepwork.mac` folder after Quit, including any SQLite companion files. Then replace the app in Applications and launch it. An unfinished timer restores paused until Resume.

**This app is ad hoc signed and not notarized by Apple.** macOS may block first launch. Only open a build you trust, following [Apple's app-opening guidance](https://support.apple.com/en-us/102445). No Gatekeeper approval, Developer ID identity or notarization is claimed; do not disable system security or remove quarantine to install it.

Save `SHA256SUMS` and `release-metadata.json` alongside the ZIP, then verify:

```sh
shasum -a 256 -c SHA256SUMS
```

The metadata records the exact source commit, positive build number, architecture, minimum macOS, toolchain and signing status. The GitHub Actions run number supplies the packaged build number.

## Included since preview 1

- **Journal and work schedules:** Day, Week and Range reports, exact clipped focus totals, completed cycles, days with focus, daily/weekly drilldown, native session tables and pagination. Separate examples never become real history. Chosen weekdays, Any day and rotating shifts support week start, reporting-day cutoff and a 14-day preview.
- **CSV and feedback:** export all matching report rows or actual history through a native Save panel. Save feedback drafts explicitly to SQLite or copy the current form without saving or sending it. Native multiline editing, validation and Undo/Redo are supported.
- **Native services:** Settings (Command-comma), Redo (Shift-Command-Z), actual Launch at Login registration and truthful approval/failure states. Slack PKCE/Keychain/status-restoration code is included, but **this build has no public Slack Client ID, so Connect Slack remains unavailable**. See [Slack setup](https://github.com/lukin-io/deep-work/blob/v0.1.0-preview.2/docs/SLACK_SETUP.md) for configuring a custom build; live Slack acceptance is pending.
- **Native fixes:** meaningful app-owned announcements without countdown chatter, feedback Tab/Shift-Tab traversal, empty-Journal focus, complete chart labels, visible keyboard chart focus retained during live updates, wrapping weekday controls, and corrected sleep/wake notification handling.
- **Existing timer behavior is preserved:** red close/Command-W hides while timing continues; the menu-bar timer reopens Focus. Command-Q pauses, saves and drains writes. Relaunch restores the last committed checkpoint paused, excluding process downtime.

## Data migration and compatibility

Upgrading from preview 1 transactionally migrates **SQLite schema 1 → 2**, preserving existing settings, schedules, session records and checkpoints while adding Slack restoration ownership storage. Credentials belong only in device-local Keychain; the release contains no user data or credentials. Migration failure preserves the existing database and reports the failure.

**Preview 1 and earlier Stage 1–4 binaries cannot open schema 2.** A rollback needs a separately preserved pre-upgrade data folder and omits sessions/settings created after that backup. Retain the upgraded folder separately before any rollback; do not delete it to make the older app run. CSV is a report format, not a restorable database backup. Stages 6 and release packaging add no further schema migration.

Explicit Save Draft semantics remain unchanged: unsaved feedback is not restored after Quit. Force Quit or a crash can lose the interval since the latest successful checkpoint. Copying only a live SQLite main file is not a reliable backup; always quit before manually copying the whole data folder.

## Verification and known limits

The merged implementation passed **361 native Swift tests**, strict concurrency compilation, compiled keyboard/layout checks, and hosted Apple Silicon Xcode Release builds on **macOS 15/Xcode 16.4/SDK 15.5** and **macOS 26/Xcode 26.6/SDK 26.5**. The tag publication workflow reruns native checks and both Xcode builds, then packages an optimized arm64 app and verifies its icon, signature integrity, metadata, checksums and archive regressions. It verifies uploaded draft assets byte-for-byte before publishing and public downloads without authentication afterward. See [implementation evidence at this tag](https://github.com/lukin-io/deep-work/blob/v0.1.0-preview.2/docs/VERIFICATION.md) and the [publication verification record](https://github.com/lukin-io/deep-work/blob/main/docs/VERIFICATION.md#preview-2--stages-16--october-19-2026) for exact run IDs and results.

- VoiceOver announcement dispatch and accessibility labels are tested; actual spoken reception and full VoiceOver traversal remain unverified.
- Launch at Login registration/removal was exercised, but actual logout/login, approval and external revocation cycles remain unverified.
- Live Slack authorization and remote status restoration are unverified and unavailable in this unconfigured build. Slack notifications, macOS Focus/Do Not Disturb and calendar integration are not implemented.
- Physical sleep/App Nap/power-loss behavior, actual system Reduce Motion propagation and a downloaded-app Gatekeeper launch remain unverified. Native notification/accounting/recovery tests do not establish those outcomes.
- Local compilation used macOS 27.0.1/Swift 6.4/Command Line Tools; full Xcode builds are hosted evidence. macOS 15 is the deployment floor, not a claim of testing every OS version.

This preview does not mark blocked acceptance items complete. The existing first preview and its assets remain unchanged.
