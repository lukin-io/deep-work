# Deep Work 0.1.0 — first preview

Native macOS app with Focus, Journal and Settings navigation, a working focus/break timer, and durable SQLite storage. This preview contains the Stage 1 foundation and Stage 2 timer; it is not the finished product.

## Download and install

Download **Deep-Work-v0.1.0-preview.1-macOS-arm64.zip** from this release's Assets, extract it, and move **Deep Work.app** to Applications. The ZIP contains the compiled application; GitHub's automatic “Source code” downloads do not.

Requires **Apple Silicon (M1 or later) and macOS 15 or later**. Intel Macs and earlier macOS versions are unsupported. Native CI runs on Apple Silicon with macOS 15; physical sleep/wake remains unverified. `release-metadata.json` identifies the exact source commit, build number, toolchain and signing status.

**This preview is ad hoc signed and is not notarized by Apple.** macOS may block first launch. Only install it if you trust this repository and understand that limitation; follow [Apple's guidance for safely opening apps](https://support.apple.com/en-us/102445). There is no instruction to disable Gatekeeper or remove quarantine. Stable distribution requires a Developer ID certificate and notarization, which are not configured.

To verify the downloaded app archive, save `SHA256SUMS` and `release-metadata.json` beside the ZIP, then run:

```sh
shasum -a 256 -c SHA256SUMS
```

## Included

- Validated focus/break durations, Repeat, Pause/Resume, manual phase changes and exact active-focus accounting.
- Red close and Command-W hide the main window while timing continues. The menu bar shows Deep work/Break and the countdown; clicking it brings Focus forward.
- Command-Q pauses and saves before exit. Relaunch restores an unfinished phase paused until Resume. Failed saves preserve recoverable in-memory changes.
- SQLite persistence for settings, configuration, saved schedule, session records/checkpoints and explicitly saved feedback drafts.
- Approved blue ring app icon and native window/navigation behavior.

## Data and compatibility

Data stays in the Foundation-resolved Application Support directory `app.deepwork.mac`. Installing the app does not bundle or replace user data. The release packaging change introduces no database migration; existing legacy JSON migration preserves original files. Quit the earlier app before installing a replacement. Unsaved feedback still requires Save Draft; a force quit can lose the interval since the last committed checkpoint.

## Validation and remaining work

The publication workflow requires native model, SQLite, AppKit and icon tests on hosted Apple Silicon, arm64 Release compilation, archive regression checks, and successful download/byte verification before publishing these assets. Local lifecycle verification covered hidden timing and Quit/relaunch recovery. Source evidence and test boundaries are in `docs/VERIFICATION.md` at the tagged revision.

Journal reports, work-schedule editing, CSV/clipboard, Launch at Login and Slack integration remain unavailable. Full VoiceOver, minimum-OS runtime, physical sleep/wake and a downloaded-app Gatekeeper launch are not claimed. This early preview is published from the app feature branch while its initial PR awaits review; it does not imply that `main` has been merged or that all 137 product items are complete.
